Build a family location database

Naledi, download the CSV file and use it to create a worksheet called Family Database in Excel or Google Sheets. Add City and Province fields, and work through the tasks you recognise.

Location rules
  • Phili M and Naledi K live in Cape Town.
  • Jabu K and family members with surname initial D or Z live in Durban.
  • Everyone else lives in Johannesburg.
City-to-province reference: Cape Town → Western Cape; Durban → KwaZulu-Natal; Johannesburg → Gauteng.

Age data practice · fictional ages only

Add an Age for every person, choosing a random whole number from 5 to 85. These ages are made up only for spreadsheet practice; they are not anyone’s real age. If you use a random formula, copy the results and paste them as values so they stay fixed.

Optional hint if you get stuck

In Excel or Google Sheets, =RANDBETWEEN(5,85) generates a whole number in that range. Fill it down for all 22 people. Copy the Age cells and use Paste Special → Values to stop them changing when the workbook recalculates.
